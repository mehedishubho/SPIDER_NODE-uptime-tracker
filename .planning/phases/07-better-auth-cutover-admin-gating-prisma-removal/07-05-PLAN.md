## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet/VPS network → :9090 | once bound non-loopback, the health port is network-reachable |
| admin browser → /admin/queues | session cookie + source IP cross the gate chain |
| Bull Board UI → BullMQ | mutation-capable queue operations (retry/remove/drain) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-07-17 | Elevation | Bull Board mutation powers behind stolen admin session | high | mitigate | two independent gates (socket-source allowlist AND admin role); D-16 audit line per hit; D-19 accepts mutation by design (operator emergency lever) |
| T-07-18 | Spoofing | forwarded-for header to dodge the IP gate | high | mitigate | allowlist keys on req.socket.remoteAddress only (prohibition; spoofed-header test case) |
| T-07-19 | Information Disclosure | healthz/readyz/metrics exposed on a non-loopback bind | medium | mitigate | per-path source gating: health/metrics answer loopback sources only, even when the port binds non-loopback for /admin/queues |
| T-07-20 | DoS | unauthenticated reachability of the mount | medium | mitigate | empty allowlist fails closed; unauthenticated requests are refused before Bull Board code runs |
