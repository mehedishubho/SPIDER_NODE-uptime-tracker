## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Redis (BullMQ) → job execution | Jobs in Redis drive worker DB writes; Redis is hardened (03-08: requirepass, loopback, AOF) |
| claim SQL → monitors table | The claim mutates next_check_at; concurrent claimers must be mutually exclusive |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-04 | Tampering | Redis poisoning of job data → bad writes | medium | mitigate | Redis loopback+auth (03-08); Postgres-side idempotency (status guard, write_guards) is the authority — Redis is never source of truth |
| T-04-05 | Denial of Service | queue flood starves transition lane | high | mitigate | Backlog cap drops routine lane above ~2x active monitors, logs+counts drops; non-UP lane never gated (RES-02) |
| T-04-06 | Tampering | duplicate/simultaneous claims double-advance next_check_at | high | mitigate | CTE-scoped FOR UPDATE SKIP LOCKED + jobId idempotency + concurrency test proving disjoint claims |
| T-04-07 | Information Disclosure | metrics endpoint | low | mitigate | Counts/ages only, loopback-bound; no job payloads (URLs) in metrics |
</threat_model>
