# Plan 06-05: Production Feature Release, Soak, and Deletion Release

## Phase Goal

**Roadmap goal (verbatim):** "The web app becomes a stateless producer — routes enqueue and never probe — and transactional email leaves the request path behind a provider interface."

**This plan's slice:** **As an** operator, **I want to** ship the feature release, watch it soak under real traffic, then delete the legacy cron path with its query-string secret for good, **so that** the modernized boundary is the only boundary (SEC-06; D-26/D-27/D-31).

<objective>
Execute the two-release structure: (1) production feature release with the setWebhook cutover and the ~24h soak gate (D-31), then (2) the deletion release removing the cron routes, legacy cron/batcher/cleanup modules, mail.ts, the retired cron secret everywhere it lives, the stale playwright writer — with the D-41 remnant gate extended and every deleted characterization pin mapped to its successor guarantee (D-27).

Purpose: SEC-06 closes only when the secret-in-query surface is deleted, and the stateless-producer conversion is only complete when the legacy in-request path is gone.
Output: Production releases with evidence; 06-PIN-INVENTORY.md; extended remnant gate; closed 06-DEPLOY-RECORD.md.
</objective>
