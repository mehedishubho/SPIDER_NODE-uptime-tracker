## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| BullMQ job data → authoritative writes | Job payloads drive Tier 1/2 writes; monitors reloaded from Postgres (never trusting job-carried URLs) |
| breaker state → enqueue admission | In-process state gates enqueueing during Postgres outages |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-21 | Tampering | stale job writing after lock loss (double-write window) | high | mitigate | isStillOwner re-verify immediately before the Tier 1 commit + abort path (WRK-04); injection case 5 (04-08) re-proves it |
| T-04-22 | Tampering | job-carried URL substituting the monitor's real URL | medium | mitigate | Processor loads url from the monitors row; job data carries only ids/epochs (source assertion) |
| T-04-23 | Denial of Service | Postgres outage snowballing retries and enqueue flood | high | mitigate | Breaker opens at 5 consecutive infra failures, enqueue gates refuse for 60 s, probe recovers (RES-01/D-33); RES-04 nothing-lost via BullMQ retries |
| T-04-24 | Information Disclosure | check logs echoing target URLs/response bodies | low | mitigate | Child loggers bind ids/timings/status only; response bodies never read beyond the byte counter |
</threat_model>
