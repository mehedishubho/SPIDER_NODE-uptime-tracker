# Plan 06-02: Email Queue Slice (Provider Interface + Lane Worker + Off-Request Sends)

## Phase Goal

**Roadmap goal (verbatim):** "The web app becomes a stateless producer — routes enqueue and never probe — and transactional email leaves the request path behind a provider interface."

**This plan's slice:** **As a** new user registering while SMTP is having a bad day, **I want to** finish registration immediately and still receive my verification email once SMTP recovers, **so that** an email outage never blocks sign-up or password reset (EML-01/02/03/05).

<objective>
Build the transactional-email vertical slice: the src/lib/email module (provider interface, byte-verbatim template relocation, enqueue helper), the worker-side email lane with the exact D-09 retry table and typed permanent-failure dead-lettering, and the two route integrations that remove in-request SMTP from register + forgot-password with loud 503 degradation (D-29).

Purpose: Email leaves the request path; the web process never opens an SMTP socket; Phase 7 Better Auth hooks will reuse this queue unchanged.
Output: New lib/email module, email lane worker + processor, rewritten send sites, three new test suites, WR-02/IN-01 worker fixes.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> register/forgot routes | Untrusted email addresses + credentials; enumeration-resistant responses required |
| route -> Redis (enqueue) | Unreachable Redis must surface as 503, never a swallowed email (D-29) |
| worker -> SMTP provider | External transport; failures must classify transient vs permanent (EML-03) |
| queued payload -> worker | Self-contained { to, subject, html } — no template state crosses the process boundary |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|

| T-06-02-02 | Denial of Service | Redis-down mid-register strands an unverifiable account | high | mitigate | Pre-flight bounded ping -> 503 before user create (Pitfall 6); residual race accepted + documented (dead-men already page Redis outages) |
